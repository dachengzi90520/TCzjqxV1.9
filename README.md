# 资金数据清洗工具

> 离线 Windows 10 桌面应用，批量处理银行资金流水 ZIP 数据包，自动完成 **解压 → 合并 → 清洗 → 主数据补全 → 字段标准化 → 去重 → 分表**，输出标准化 XLSX，供办案分析使用。

- **版本**：V1.9
- **版权**：济宁经侦-田成 57018 © 2026
- **目标环境**：Windows 10 内网（无互联网），全部依赖打包进单个 EXE

---

## 功能特性

- 一键导入案件 ZIP（支持多选），自动解压银行流水数据包
- 自动识别 `{银行名}{CSV类型}.zip` 文件名，按 **7 种 CSV 类型** 归类
- 同类多银行 CSV 自动 **流式合并**，新增「银行来源」列
- 交易流水先做 **全字段去重**，标准化后再按 **6 字段**最终去重
- 交易时间和交易金额 **同时为空**时才删除记录
- 从账户信息表按 VLOOKUP 语义补全空白卡号、账号、户名和证件号码
- 交易金额、交易余额转为数值并显示两位小数；收付标志统一为「出 / 进」
- 自动清理卡号/账号中的 `-`、`_` 等附加字符
- 输出标准化 **汇总 XLSX**，超大表自动分片（>1,048,576 行）
- 按 **银行 + 户名 + 账号** 自动 **分表**，生成独立 XLSX
- 长数字列（卡号/账号/证件号码等）强制文本格式，**防止科学计数法**
- 中文编码自动检测（GBK/GB18030），兼容不同银行命名差异
- **V1.9**：交易流水严格按需求执行 8 步：清空白、全字段去重、双空删除、卡号/账号补全、户名/证件号码补全、金额数值化、收付标志标准化、6 字段最终去重
- **V1.7**：兼容"逐卡"新版反馈包——交易明细文件名带卡号 `{银行}交易明细信息({卡号}).zip`，自动识别并用文件名卡号补全为空的交易卡号；旧版包仍走 V1.6 原逻辑

## 资金交易流水处理流程（V1.9，8 步）

```
清空前后空白 → 全字段去重 → 交易时间与交易金额同时为空则删除
→ 按账户表补全卡号/账号 → 按账户表补全户名/证件号码
→ 金额数值化(两位小数) → 收付标志标准化 → 6字段最终去重
→ CSV转XLSX → 超限分片 → 按户名分表
```

| 步骤 | 处理 | 对应模块 |
|------|------|----------|
| 1 | 清空资金流水所有字段前后空白 | `core/cleaner.py` + `core/deduper.py` |
| 2 | 以全部字段相同判定重复，保留首行 | `core/deduper.py` |
| 3 | 删除「交易时间」和「交易金额」同时为空的行 | `core/cleaner.py` |
| 4 | 依账户表对应关系补全空白交易卡号、交易账号 | `core/completer.py` |
| 5 | 依账户表补全空白交易户名、交易证件号码 | `core/completer.py` |
| 6 | 交易金额、交易余额转数值，保留两位小数 | `core/cleaner.py` + `core/converter.py` |
| 7 | 借/1/D/d/转出→出；贷/2/C/c/入/转入→进，其余保持 | `core/cleaner.py` |
| 8 | 按 6 字段最终去重 | `core/deduper.py` |

最终去重键为交易卡号、交易时间、交易金额、交易余额、收付标志、交易对手账卡号。账户信息表及其他表的清洗、去重和输出逻辑保持原版本不变。

## 项目结构

```
资金清洗项目/
├── main.py              ← PySide6 GUI 入口
├── build.spec           ← PyInstaller 打包配置
├── requirements.txt     ← 依赖清单
├── resources/icon.ico   ← 程序图标
├── core/
│   ├── extractor.py     ← 解压：从银行ZIP文件名解析银行名+CSV类型
│   ├── merger.py        ← 合并：按类型合并CSV（添加银行来源列）
│   ├── converter.py     ← CSV→XLSX（长数字列强制文本格式防科学计数法）
│   ├── deduper.py       ← 去重（流水先全字段，最终按6字段）
│   ├── cleaner.py       ← 清洗与金额/收付标志标准化
│   ├── completer.py     ← 账户表 VLOOKUP 补全（先键、后身份信息）
│   ├── splitter.py      ← 分表（按 银行_户名 输出独立XLSX）
│   └── pipeline.py      ← 流程编排 + 进度回调
├── utils/
│   ├── config.py        ← 常量、CSV类型关键词、parse_bank_zip_name()
│   ├── encoding.py      ← chardet编码检测
│   ├── csv_utils.py     ← 分隔符检测 + read_csv_auto
│   └── logger.py        ← 错误日志（INFO/WARN/ERROR）
└── tests/               ← 单元测试与端到端回归测试
```

## Win10 内网部署

1. 安装 Python 3.12（勾选 **Add to PATH**）
2. 离线安装依赖：`pip install --no-index --find-links=.\依赖 -r requirements.txt`
3. `python main.py` 源码测试
4. 有错误 → 拷贝 `error.log` 返回 Mac 修复
5. 无误 → `pyinstaller build.spec` → 输出 `dist/资金数据清洗工具.exe`

> `.gitignore` 已忽略 `依赖/`（离线 .whl 可用 `pip download` 重新生成）与 `dist/`（打包产物）。

## GUI 使用说明

1. 启动程序（`资金数据清洗工具.exe` 或 `python main.py`）
2. 点击「选择ZIP文件」——可多选，通常是案件包的顶层 ZIP
3. 选择输出目录（默认桌面）
4. 设置选项（保留中间文件 / 遇错停止）
5. 点击「▶ 开始处理」——程序在子线程执行完整流程，界面上实时显示当前步骤与进度
6. 完成后在输出目录查看各分类 XLSX 与「分表」文件夹
7. 查看输出目录下的 `error.log` 了解每一步详情与错误

> 处理过程中请勿关闭窗口；若勾选「遇错停止」，出错会立即中断并提示，否则继续并记录日志。

## 数据格式要点

- **ZIP 结构**：顶层 ZIP 内含多个 `{银行名}{CSV类型}.zip`（每个银行 ZIP 仅 1 个 CSV），另有 `任务信息(成功/失败).csv`
- **编码**：全部 GBK / GB18030（chardet 对短中文文本置信度低，需强制信任）
- **分隔符**：逗号 `,`（字段用双引号包裹，字段值尾部含 `\t`）
- **CSV 类型（7 种）**：关联子账户信息、强制措施信息、任务信息(成功)、任务信息(失败)、交易明细信息、人员信息、账户信息

### 关键列名差异（模糊匹配兼容）

| 预期 | 实际 |
|------|------|
| 去重列「收费标志」 | 「收付标志」 |
| 账户表「交易户名」 | 「账户开户名称」 |
| 账户表「交易证件号码」 | 「开户人证件号码」 |
